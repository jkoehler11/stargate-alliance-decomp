# Oracle diff: reconstructed build vs the 2006 studio source

Generated by `tools/oracle-diff.py`. The 2006 `Classes` tree is held privately and never
enters this repository; this report carries class names, counts and scores only.

## Method

Classes are matched by name. Similarity is the mean of two Jaccard scores over the
normalised source: distinct identifiers (declarations and references, keywords and
`__NFUN_n__` placeholders excluded) and declared function names. Both are insensitive to
formatting, so decompiler style cannot flatter or punish the result. Buckets:

- **matched** similarity >= 0.75: the decompiler reproduced the class faithfully
- **drifted** 0.35 <= similarity < 0.75: same class, changed between the build and the leak
- **divergent** similarity < 0.35: same name, little shared structure
- **build-only**: in the Dec 2005 build, absent from the leak
- **oracle-only**: in the leak, absent from the build (work done after Dec 2005)

This is the important finding: the leaked tree is **Perception's modified Engine source**
(`Engine` + a handful of `Core` classes), plus a few game classes and the two
script-compiled-to-C++ classes (`Pawn`, `ShadowProjector`). It is not a dump of the game's
own script packages, so it cannot be used as a completeness oracle for `StargateGame`,
`StargateContent` or `StargateVehicles` -- those are `build-only` by construction, and that
bucket is **not** evidence of cut content. What the oracle is good for:

1. A quality measurement of the decompiler on 278 classes of known source (mean similarity
   above), which is the number to watch as the token map improves (PLAN 3.5).
2. A change log of Perception's engine work between Dec 2005 and Jun 2006 -- the drifted and
   divergent Engine classes are precisely the subsystems they were still rewriting, which
   feeds PLAN 4.8 (fork changes vs stock UE2.5).
3. Confirmation of the ucpp trap (`PLAN` risk 4): `Pawn.ucpp`/`Pawn.cpp` and
   `ShadowProjector.ucpp`/`.cpp` exist beside thin `.uc` files, so their behaviour is in the XBE.

## Reproducing

```sh
ORACLE_DIR=/path/to/private/Classes make oracle-diff
```

The oracle path comes from the environment on purpose: no contributor's filesystem layout
ends up in the repository, and the run is expected to be impossible for anyone without the
private source -- the committed report is the artefact.
