## What each class's extraction path is

umodel names the class as it writes the object; the path below is the one this run took, so
it is measured rather than declared.

| class family | path | note |
|---|---|---|
| `Texture`, `Shader`, `Combiner`, `FinalBlend`, `TexEnvMap`, `TexOscillator`, `TexPanner`, `TexRotator`, `TexScaler` | umodel `-png` | one image per material/master object |
| `StaticMesh`, `VertMesh` | umodel `-gltf` | `.gltf` + `.bin` per mesh |
| `SkeletalMesh`, `MeshAnimation` | umodel `-gltf` | animations are the class that umodel's `MeshAnimation::Serialize` still refuses in 14 packages |
| `Sound` | **not umodel** | umodel leaves unread bytes in every `.uax` (`USound::Serialize`; 53 of 55 packages failed), so sounds stay with this project's own reader (`docs/DIALOGUE.md`, PLAN 5.3, 3,287 WAVs indexed) |

`-nostat` is **not** a quiet flag in this umodel: it means *do not load StaticMesh* and it
silently exported 0 objects for 81 of the 91 mesh packages in the first pass. The driver
therefore carries a retry ladder: a package that fails is retried with `-noanim`, which skips
the `MeshAnimation` class umodel cannot finish parsing and still exports that package's meshes
and textures. The `flags` column records which rung produced the row.
