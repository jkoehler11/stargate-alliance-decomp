## Reading this table

- `classes.csv` counts classes this package *defines* (exports), not classes it references.
- `is_native` is true when the class owns `native` functions: UE2 has no plain class-level
  `native` bit in `ClassFlags`, so ownership is the only mechanical definition. `native_only`
  records the separate `CLASS_NativeOnly` bit.
- A class count lower than the leaked 2006 source is expected: this build is six months older
  and the leak is an oracle, not ground truth (`PLAN.md` risk 5).
