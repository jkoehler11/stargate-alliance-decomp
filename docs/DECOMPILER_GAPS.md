## How to close these

1. Classify each token: bytecode operator (below the native index range) vs a `native()`
   entry that has no name because the function lives in a class this build does not ship.
2. For operators, extend the UE2.5 token map in UELib (per-build override) with the operator
   names the grammar expects, then re-run `make decompile` and diff this report.
3. For natives, cross-reference `inventory/natives.csv`: a token that collides with a known
   `native()` index in the same package is a nameable call, not an operator.
4. Track the trend, not the absolute number: the goal is monotone decrease per token fixed.
