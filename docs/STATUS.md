## Reading the native rows

`functions carrying a name` counts every function whose name is not `FUN_*`: assert-derived file
attribution, the runtime `GNatives` names, class-registration overrides, and the `Vtbl_*` tables are
not functions and are excluded. Naming the remaining `FUN_*` set needs the signature databases that
this repository may not carry (`docs/UNKNOWNS.md` U9), so the ceiling without them is not 100%.
