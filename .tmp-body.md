## What this is

One thread -- class registration (U40): the 250 tables no registration names. The previous read split them by
the shape of the body that installs them and left the naming to "the body, not the class map". This bundle
reads those bodies and measures the three channels a constructor still offers, keeping the 474 named tables
as the control for every one of them. Everything lands in `inventory/class_ctor_evidence.csv` (724 rows) and
one new page section with a generated block.

## Items, and the measurement that settled each

1. **One body read per table: literals, named callees, parent.** `tools/class-ctor-evidence.py` reads each
   installer body once and records the printable UTF-16 literals it pushes (a `push imm32` outside `.text`),
   the map's own `Core_*`/`Engine_*` names among the bodies it calls, and the parent its first call reaches.
   `--check` is a synthetic image with 18 assertions (a literal that must decode, an ASCII blob and a small
   integer that must not, an `ini:` section, a thunk into the parent's store, a two-table body that must give
   no edge, an absolute store that is not an install); `--check-doc` rebuilds the block from the CSV with no
   dump; the artifact reproduces byte for byte on a second run.

2. **The literal channel is closed, by its own control.** Of the 990 installer bodies behind the 474 named
   tables, 26 push a printable literal, 16 of those tables push *some* class name, and **none pushes its own
   class**; the two `ini:` literals name the class that declares the config property
   (`DemoPlayPendingLevel` -> `ini:Engine.Engine.DemoRecordingDevice`). So the answer to "name the 97 from
   their constructor literals" is no -- and the channel instead gives object layout: 70 of the 246 nameless
   tables push a literal, 5 an `ini:` section that does name a class (`0x004c93c4`, `0x004c93c8`,
   `0x004c93d0` are the `Canvas`/`Input` pair's objects, `0x004fc610` the demo recording device's,
   `0x005139f4` the network device's), and the rest are field defaults (`Z:\Cache`, `Z:\Help`, `Z:\Maps` and
   `D:\` on the file manager `0x004c8db8`, which then calls `_CreateDirectoryA@8`).

3. **The callee channel places a table in a subsystem and never names it.** 169 of the 246 nameless tables
   call a named body; 31 signatures are shared by two or more, the widest 33 tables whose only callee is
   `__allmul`, the next 10 whose only one is `Core_UnTemplate`. Reported as families, not promoted to labels.

4. **The parent edge, held to the script tree.** A table's own installer is the body whose *last* store is
   that table (the rule the site census already uses) and its first call through the null-check thunk is the
   parent's constructor: on the named population that is the script `super` 167 times, a further ancestor 211
   times (a script-only class installs its table from a body that calls its nearest native base), a class
   with no script chain 53 times -- **0 contradictions**. On the nameless side 55 of the 246 get an edge (7 to
   a named class, 48 to another nameless table) and 9 climb to a named class, deepest 3, so the tree says
   which native ancestor they run and not what they are called.

5. **The four tables with no installer body are not tables.** `0x004f70a0` is 2 dwords at the tail of the
   44-dword run `I3DL2Listener`'s 30-slot table heads; `0x005181dc` is 3 dwords into a 6-dword table whose
   head holds two `__purecall` entries; `0x0053f7c4` is 21 dwords into a run of 2-mod-4 in-function offsets
   (an exception-scope table, not a vtable); `0x005172ec` starts a 27-dword run after the UTF-16 string
   `mesh!!`. None has its recorded store site inside a body of the map -- which is why the census listed it.

6. **The 97 get their own row, and the page sentence they contradict is corrected.** The
   `installed-by-ctor` row: 20 push a literal, 55 call a named body, 28 have a base edge. The installer-shape
   section's "the naming channel for those is the body, not the class map" now points at the reading instead
   of promising a name, and U40 gains the numbers plus a corrected "what is left".
